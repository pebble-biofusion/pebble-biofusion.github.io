# Images Directory

Place your images here and reference them in your markdown files.

## Usage

In your markdown files:

```markdown
![Alt text](images/your-image.png)

![Figure description](images/graph.png)

*Figure: Description of the figure*
```

## Supported Formats

- PNG
- JPEG/JPG
- GIF
- SVG
- WebP

## Tips

- Use descriptive filenames (e.g., `workflow-diagram.png` not `image1.png`)
- Optimize images for web (keep file sizes reasonable)
- Use appropriate formats (PNG for graphics, JPG for photos)
- Consider image resolution for readability
